
# 🏥 Hospital Emergency Room Dashboard | Microsoft Excel

## 📌 Project Overview

The Hospital Emergency Room Dashboard is an interactive data analysis project developed using Microsoft Excel. The main objective of this project is to analyze hospital emergency room data and monitor patient admissions, waiting times, satisfaction scores, and department referrals.

The dashboard provides a clear overview of hospital performance through interactive charts, KPI cards, and filters.

## 🎯 Project Objectives

- Analyze patient admission and non-admission patterns.
- Monitor average patient waiting time.
- Evaluate patient satisfaction scores.
- Understand gender-wise and age-group-wise patient distribution.
- Analyze department-wise patient referrals.
- Track monthly and yearly patient trends.

## 🛠️ Tools & Technologies Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Cleaning
- Data Analysis
- Data Visualization

## 📊 Dashboard Features

### 1. Key Performance Indicators (KPIs)
- Total Number of Patients
- Average Waiting Time
- Patient Satisfaction Score

### 2. Patient Attendance Analysis
Visualizes the percentage of patients attended on time and those who experienced delays.

### 3. Gender-wise Analysis
Shows the distribution of male and female patients.

### 4. Admission Status Analysis
Displays admitted and non-admitted patients with their respective percentages.

### 5. Age Group Analysis
Shows patient distribution across different age groups.

### 6. Department Referral Analysis
Identifies patient referrals across different hospital departments, including General Practice, Orthopedics, Cardiology, and others.

### 7. Interactive Filters
Allows users to filter dashboard data by year and month.

## 🔍 Key Insights

- A total of 513 patients were recorded for the selected January 2024 reporting period.
- Approximately 52.44% of patients were admitted, while 47.56% were not admitted.
- The average waiting time was 36.32 minutes, with a patient satisfaction score of 4.96.

## 🚀 How to Use the Project

1. Clone or download this repository.
2. Open `Hospital_Emergency_Room_Dashboard.xlsx` in Microsoft Excel.
3. Enable editing if prompted.
4. Use the Year and Month filters to explore the dashboard.
5. Analyze patient admissions, waiting times, satisfaction scores, and department referrals.
